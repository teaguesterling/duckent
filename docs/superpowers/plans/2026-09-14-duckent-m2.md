# duckent M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nested `HAS`/`NOT` matching, two css front-ends bound by a parser differential, typed `ATTR MAP` comparisons, element-aware sibling relations, the pseudo-class binding forms, and a differential harness against sitting_duck, all as macros on the M0–M1½ prototype.

**Architecture:** The match compiler becomes a bottom-up fold over the selector IR (a `USING KEY` recursive CTE) that emits `EXISTS`/`NOT EXISTS` groups; every structural relation is one fragment macro shared by combinators, groups, and the traversal macros; the semantic columns are one fragment shared by both projection branches. Two css parsers, a Python one in the runner and a SQL lowering of tree-sitter-css rows, produce the same `TREE_SELECTOR`. The corpus imports astcss-eval's execution-verified pairs with their frozen `file:node_id` references, so the sitting_duck differential runs without sitting_duck installed.

**Tech Stack:** DuckDB 1.5.5 (Python package and CLI), SQL macros, Python 3 for the runner and the css parser, sitting_duck only under `require` and for fixture generation.

**Spec:** `docs/superpowers/specs/2026-09-14-duckent-m2-design.md` (and the core design it extends, `docs/superpowers/specs/2026-09-13-duckent-core-design.md`).

## Global Constraints

- DuckDB 1.5.5. Inside macro bodies access struct fields with parentheses `(x).f`; lambdas use `lambda x: ...` / `lambda x, i: ...` (index is 1-based); `query()` accepts text only from macros with no SELECT in their body (`tree_compile_projection`, `tree_project`, `tree_apply`, `tree_derive_parent`, `tree_encode`); the DDL/DML/match compilers are executed by `test/run.py` and may use CTEs. A `USING KEY` recursive term must be one SELECT and may reference `recurring.<cte>` only in FROM position (never inside a correlated subquery). A bare `error(...)` in a CASE branch is lazy; `(SELECT error(...))` is not.
- Canonical columns are `_root, _pre, _level, _parent, _size, _children, _next, _type, _id, _classes, _attr_map, _element, _pseudo` (this milestone adds `_element`). `tree_canonical_columns()` is the one list.
- Every macro is `CREATE OR REPLACE`; every refusal is `error('<function>: <what, naming the slot or clause>')`; attribute and pseudo filters are NULL-definite (`COALESCE(..., false)`).
- Mutant ids are permanent: MN22–MN25 are the handover's; never mint others. Copy-and-edit mutants must be regenerated from the current macro whenever the base macro changes.
- Tests are sqllogictest `.test` files under `test/sql/`, run with `python3 test/run.py test/sql`; `python3 test/run_mutants.py` must end with `all mutants killed`. Both must be green at every commit.
- Commit messages: `feat(m2): ...`, `fix(m2): ...`, `test(m2): ...`, `docs(m2): ...`, ending with the two attribution lines the session prescribes.

```sql
CREATE TYPE TREE_SEMANTIC AS STRUCT(
  type VARCHAR, id VARCHAR, classes VARCHAR, attr VARCHAR, attr_map VARCHAR, element VARCHAR,
  pseudo STRUCT(name VARCHAR, body VARCHAR, macro VARCHAR, args VARCHAR, prefix VARCHAR)[]);

-- pseudo: a list of any of {name, body} | {name, macro, args} | {prefix, args}; pseudo_map: MAP of name -> macro
-- with pseudo_args shared by every entry; the constructor flattens the map into the list.
CREATE OR REPLACE MACRO tree_semantic(type := NULL, id := NULL, classes := NULL, attr := NULL, attr_map := NULL, element := NULL,
                                      pseudo := NULL, pseudo_map := NULL, pseudo_args := NULL) AS
  {type: type, id: id, classes: classes, attr: attr, attr_map: attr_map, element: element,
   pseudo: CASE WHEN pseudo IS NULL AND pseudo_map IS NULL THEN NULL ELSE list_concat(
     COALESCE(pseudo::STRUCT(name VARCHAR, body VARCHAR, macro VARCHAR, args VARCHAR, prefix VARCHAR)[], []),
     CASE WHEN pseudo_map IS NULL THEN [] ELSE list_transform(map_entries(pseudo_map),
       lambda e: {name: (e).key, body: NULL::VARCHAR, macro: (e).value, args: pseudo_args, prefix: NULL::VARCHAR}) END) END
  }::TREE_SEMANTIC;

-- Expand macro, map and prefix bindings to expression bodies. Prefix entries bind every catalog
-- scalar macro whose name starts with the prefix; name = the remainder. Reads duckdb_functions(),
-- so it is called by the DDL compilers (runner-executed), never by tree_compile_projection.
CREATE OR REPLACE MACRO tree_expand_pseudo(sem) AS (
  SELECT {type: (sem).type, id: (sem).id, classes: (sem).classes, attr: (sem).attr, attr_map: (sem).attr_map, element: (sem).element,
    pseudo: CASE WHEN (sem).pseudo IS NULL THEN NULL ELSE list_concat(
      list_transform(list_filter((sem).pseudo, lambda p: (p).prefix IS NULL),
        lambda p: {name: (p).name, body: COALESCE((p).body, (p).macro || '(' || COALESCE((p).args, '') || ')'),
                   macro: (p).macro, args: (p).args, prefix: NULL::VARCHAR}),
      COALESCE((SELECT list({name: substr(f.function_name, length((x).px.prefix) + 1),
                             body: f.function_name || '(' || COALESCE((x).px.args, '') || ')',
                             macro: f.function_name, args: (x).px.args, prefix: (x).px.prefix} ORDER BY f.function_name)
                FROM (SELECT unnest(list_filter((sem).pseudo, lambda p: (p).prefix IS NOT NULL)) AS px) x
                JOIN (SELECT DISTINCT function_name FROM duckdb_functions() WHERE function_type = 'macro') f
                  ON starts_with(f.function_name, (x).px.prefix)), [])) END
  }::TREE_SEMANTIC);

-- The type a comparison literal implies: numbers and booleans cast the map value; quoted text compares as VARCHAR.
CREATE OR REPLACE MACRO tree_sql_literal_type(arg) AS
  CASE WHEN regexp_matches(trim(arg), '^-?[0-9]+$') THEN 'BIGINT'
       WHEN regexp_matches(trim(arg), '^-?[0-9]*\.[0-9]+$') THEN 'DOUBLE'
       WHEN lower(trim(arg)) IN ('true', 'false') THEN 'BOOLEAN'
       ELSE NULL END;
```

Replace `tree_sql_comb` in `sql/07_match.sql` with:

```sql
-- One fragment per relation, each the single definition shared by combinators, groups and traversal.
-- a and b are step aliases; p is the projection relation text (needed where a third row is scanned);
-- elem says whether the tree declares ELEMENT, in which case sibling and positional relations see element rows only.
CREATE OR REPLACE MACRO tree_sql_subtree(a, b) AS
  b || '._root = ' || a || '._root AND ' || b || '._pre BETWEEN ' || a || '._pre + 1 AND ' || a || '._pre + ' || a || '._size';
CREATE OR REPLACE MACRO tree_sql_children(a, b) AS
  b || '._root = ' || a || '._root AND ' || b || '._parent = ' || a || '._pre';
CREATE OR REPLACE MACRO tree_sql_parent(a, b) AS
  b || '._root = ' || a || '._root AND ' || b || '._pre = ' || a || '._parent';

CREATE OR REPLACE MACRO tree_sql_siblings(a, b) AS
  b || '._root = ' || a || '._root AND ' || b || '._parent IS NOT DISTINCT FROM ' || a || '._parent AND ' || b || '._pre <> ' || a || '._pre';
CREATE OR REPLACE MACRO tree_sql_after(a, b) AS
  tree_sql_siblings(a, b) || ' AND ' || b || '._pre > ' || a || '._pre AND ' || b || '._element';
CREATE OR REPLACE MACRO tree_sql_before(a, b) AS
  tree_sql_siblings(a, b) || ' AND ' || b || '._pre < ' || a || '._pre AND ' || b || '._element';
CREATE OR REPLACE MACRO tree_sql_next_sibling(a, b, p, elem) AS
  CASE WHEN elem THEN tree_sql_after(a, b) || ' AND NOT EXISTS (SELECT 1 FROM ' || p || ' __c WHERE ' || tree_sql_siblings(a, '__c')
                        || ' AND __c._pre > ' || a || '._pre AND __c._pre < ' || b || '._pre AND __c._element)'
       ELSE tree_sql_siblings(a, b) || ' AND ' || b || '._pre = ' || a || '._pre + ' || a || '._size + 1' END;
CREATE OR REPLACE MACRO tree_sql_prev_sibling(a, b, p, elem) AS
  CASE WHEN elem THEN tree_sql_before(a, b) || ' AND NOT EXISTS (SELECT 1 FROM ' || p || ' __c WHERE ' || tree_sql_siblings(a, '__c')
                        || ' AND __c._pre < ' || a || '._pre AND __c._pre > ' || b || '._pre AND __c._element)'
       ELSE tree_sql_siblings(a, b) || ' AND ' || a || '._pre = ' || b || '._pre + ' || b || '._size + 1' END;
CREATE OR REPLACE MACRO tree_sql_first_child(a, p, elem) AS
  CASE WHEN elem THEN a || '._element AND NOT EXISTS (SELECT 1 FROM ' || p || ' __c WHERE ' || tree_sql_siblings(a, '__c') || ' AND __c._pre < ' || a || '._pre AND __c._element)'
       ELSE a || '._pre = ' || a || '._parent + 1' END;
CREATE OR REPLACE MACRO tree_sql_last_child(a, p, elem) AS
  CASE WHEN elem THEN a || '._element AND NOT EXISTS (SELECT 1 FROM ' || p || ' __c WHERE ' || tree_sql_siblings(a, '__c') || ' AND __c._pre > ' || a || '._pre AND __c._element)'
       ELSE 'NOT EXISTS (SELECT 1 FROM ' || p || ' __c WHERE ' || tree_sql_siblings(a, '__c') || ' AND __c._pre > ' || a || '._pre)' END;
CREATE OR REPLACE MACRO tree_sql_root(a) AS a || '._level = 0';

-- Combinator between the previous step alias a and this step alias b. MN14 mutates tree_sql_subtree/children.
CREATE OR REPLACE MACRO tree_sql_comb(op, a, b, p, elem) AS
  CASE op
    WHEN 'desc'  THEN tree_sql_subtree(a, b)
    WHEN 'child' THEN tree_sql_children(a, b)
    WHEN 'next'  THEN tree_sql_next_sibling(a, b, p, elem)
    WHEN 'after' THEN tree_sql_after(a, b)
    ELSE error('tree_match: unknown combinator ' || op) END;
```

```sql
-- One level of step normalization: the fixed struct every literal level is cast to.
-- L0 has no groups; L1 groups hold L0 steps; L2 groups hold L1 steps; the constructor's argument is L2.
CREATE OR REPLACE MACRO tree_steps_l0_type() AS 'STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR)[]';

-- Emit the IR rows of one step chain as a list of structs, with node ids allocated from `base`, parent `parent_id`,
-- first-step op `first_op` (NULL for a top-level chain, 'desc' by default inside a group).
-- Returns STRUCT(node_id, parent_id, kind, value, op, arg, alias)[] ordered by node_id. Pure list functions only.
CREATE OR REPLACE MACRO tree_steps_rows(steps, base, parent_id, first_op) AS (
  WITH st AS (SELECT generate_subscripts(steps, 1) AS i, unnest(steps) AS s),
  nodes AS (
    SELECT i, 0 AS sub, 'step' AS kind, NULL::VARCHAR AS value,
           CASE WHEN i = 1 THEN COALESCE((s).comb, first_op) ELSE COALESCE((s).comb, 'desc') END AS op, NULL::VARCHAR AS arg, (s)."as" AS alias, NULL::JSON AS grp FROM st
    UNION ALL SELECT i, 1, 'type', (s).type, NULL, NULL, NULL, NULL FROM st WHERE (s).type IS NOT NULL
    UNION ALL SELECT i, 2, 'id', (s).id, NULL, NULL, NULL, NULL FROM st WHERE (s).id IS NOT NULL
    UNION ALL SELECT i, 3, 'class', (s).class, NULL, NULL, NULL, NULL FROM st WHERE (s).class IS NOT NULL
    UNION ALL SELECT i, 4, 'attr',
        regexp_extract((s).attr, '^\s*([A-Za-z_][A-Za-z0-9_]*)\s*(=|!=|<>|<=|>=|<|>|LIKE|ILIKE|NOT LIKE)\s*(.+?)\s*$', 1),
        regexp_extract((s).attr, '^\s*([A-Za-z_][A-Za-z0-9_]*)\s*(=|!=|<>|<=|>=|<|>|LIKE|ILIKE|NOT LIKE)\s*(.+?)\s*$', 2),
        regexp_extract((s).attr, '^\s*([A-Za-z_][A-Za-z0-9_]*)\s*(=|!=|<>|<=|>=|<|>|LIKE|ILIKE|NOT LIKE)\s*(.+?)\s*$', 3), NULL, NULL FROM st WHERE (s).attr IS NOT NULL
    UNION ALL SELECT i, 5, 'pseudo', (s).pseudo, NULL, NULL, NULL, NULL FROM st WHERE (s).pseudo IS NOT NULL
    UNION ALL SELECT i, 6, 'where', (s)."where", NULL, NULL, NULL, NULL FROM st WHERE (s)."where" IS NOT NULL),
  numbered AS (SELECT CAST(base + row_number() OVER (ORDER BY i, sub) - 1 AS INTEGER) AS node_id, * FROM nodes),
  parented AS (
    SELECT n.node_id,
           CASE n.kind WHEN 'step' THEN parent_id ELSE (SELECT p.node_id FROM numbered p WHERE p.kind = 'step' AND p.i = n.i) END AS parent_id,
           n.kind, n.value, n.op, n.arg, n.alias
    FROM numbered n)
  SELECT list({node_id: node_id, parent_id: parent_id, kind: kind, value: value, op: op, arg: arg, alias: alias} ORDER BY node_id) FROM parented);
```

Groups need node ids allocated after the outer chain's rows, so the constructor builds the outer rows, then for each step with a `has`/`not` field appends a group node and the inner chain's rows (recursively for the second level). Write the constructor as three nested applications, one per literal level, and a final renumbering that keeps parent links:

```sql
CREATE OR REPLACE MACRO tree_steps(steps) AS (
  WITH
  -- the L2 cast: groups two deep
  s2 AS (SELECT steps::STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR,
                  has STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR,
                      has STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR)[],
                      "not" STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR)[])[],
                  "not" STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR,
                      has STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR)[],
                      "not" STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR)[])[])[] AS v),
  raw AS (SELECT unnest(steps) AS s0),
  bad_key AS (SELECT min(k) AS k FROM (SELECT unnest(json_keys(to_json(s0))) AS k FROM raw)
              WHERE k NOT IN ('comb', 'type', 'id', 'class', 'attr', 'pseudo', 'where', 'as', 'has', 'not')),
  -- flatten: every step at every level becomes a row with its level path; groups become rows too
  lvl0 AS (SELECT generate_subscripts(v, 1) AS i0, unnest(v) AS s FROM s2),
  g1 AS (SELECT i0, 'has' AS gkind, (s).has AS inner FROM lvl0 WHERE (s).has IS NOT NULL
         UNION ALL SELECT i0, 'not', (s)."not" FROM lvl0 WHERE (s)."not" IS NOT NULL),
  lvl1 AS (SELECT g.i0, g.gkind, generate_subscripts(g.inner, 1) AS i1, unnest(g.inner) AS s FROM g1 g),
  g2 AS (SELECT i0, gkind, i1, 'has' AS gkind2, (s).has AS inner FROM lvl1 WHERE (s).has IS NOT NULL
         UNION ALL SELECT i0, gkind, i1, 'not', (s)."not" FROM lvl1 WHERE (s)."not" IS NOT NULL),
  lvl2 AS (SELECT g.i0, g.gkind, g.i1, g.gkind2, generate_subscripts(g.inner, 1) AS i2, unnest(g.inner) AS s FROM g2 g),
  bad_capture AS (SELECT count(*) AS n FROM (SELECT (s)."as" AS a FROM lvl1 UNION ALL SELECT (s)."as" FROM lvl2) WHERE a IS NOT NULL),
  -- rows, in document order: outer steps and their clauses, then each group node followed by its inner chain
  outer AS (SELECT unnest(tree_steps_rows((SELECT list({comb: (s).comb, type: (s).type, id: (s).id, class: (s).class, attr: (s).attr, pseudo: (s).pseudo, "where": (s)."where", "as": (s)."as"} ORDER BY i0) FROM lvl0)::STRUCT(comb VARCHAR, type VARCHAR, id VARCHAR, class VARCHAR, attr VARCHAR, pseudo VARCHAR, "where" VARCHAR, "as" VARCHAR)[], 1, 0, NULL)) AS r),
  outer_steps AS (SELECT (r).node_id AS step_node, row_number() OVER (ORDER BY (r).node_id) AS i0 FROM outer WHERE (r).kind = 'step'),
  base1 AS (SELECT COALESCE(max((r).node_id), 0) + 1 AS b FROM outer)
  SELECT CASE
    WHEN (SELECT k FROM bad_key) IS NOT NULL THEN error('tree_steps: unknown step field ' || (SELECT k FROM bad_key))
    WHEN (SELECT n FROM bad_capture) > 0 THEN error('tree_steps: capture inside HAS/NOT has no row to bind')
    ELSE tree_steps_assemble(
      [{node_id: 0, parent_id: NULL::INTEGER, kind: 'selector', value: NULL::VARCHAR, op: NULL::VARCHAR, arg: NULL::VARCHAR, alias: NULL::VARCHAR}]
      || (SELECT list(r ORDER BY (r).node_id) FROM outer),
      (SELECT list({i0: g.i0, gkind: g.gkind, step_node: o.step_node,
                    inner: list_transform(g.inner, lambda s: {comb: (s).comb, type: (s).type, id: (s).id, class: (s).class, attr: (s).attr, pseudo: (s).pseudo, "where": (s)."where", "as": (s)."as"}),
                    inner2: (SELECT list({i1: x.i1, gkind2: x.gkind2, inner: x.inner}) FROM g2 x WHERE x.i0 = g.i0 AND x.gkind = g.gkind)}
                   ORDER BY g.i0, g.gkind)
       FROM g1 g JOIN outer_steps o ON o.i0 = g.i0)) END
  FROM base1);
```

The assembly macro appends group nodes and inner chains with fresh ids. Because `tree_steps_rows` allocates ids from a base, the assembly is a fold over the group list; implement it as a recursive CTE over the list index (pure, no table reads):

```sql
-- Append groups to an outer chain: for each (step_node, kind, inner steps[, inner groups]) allocate a group node
-- and the inner chain's rows after the current maximum id. Second-level groups are appended the same way.
CREATE OR REPLACE MACRO tree_steps_assemble(rows, groups) AS (
  WITH RECURSIVE acc(k, out) USING KEY (k) AS (
    SELECT 0 AS k, rows AS out
    UNION ALL
    SELECT a.k + 1,
      a.out
      || [{node_id: (SELECT max((r).node_id) FROM (SELECT unnest(a.out) AS r)) + 1, parent_id: (g).step_node, kind: (g).gkind,
           value: NULL::VARCHAR, op: NULL::VARCHAR, arg: NULL::VARCHAR, alias: NULL::VARCHAR}]
      || tree_steps_rows((g).inner, (SELECT max((r).node_id) FROM (SELECT unnest(a.out) AS r)) + 2,
                         (SELECT max((r).node_id) FROM (SELECT unnest(a.out) AS r)) + 1, 'desc')
    FROM acc a, (SELECT groups[a.k + 1] AS g) x WHERE a.k < len(groups))
  SELECT tree_steps_assemble2(out, groups) FROM acc WHERE k = len(groups));
```

and `tree_steps_assemble2(rows, groups)` repeats the same fold for each group's `inner2` list, resolving each inner group's parent step as the `k`-th step node of that group's inner chain (count `step` rows under the group node in order). The result is cast `::TREE_SELECTOR`. If the recursive-CTE-over-a-list form fights the binder (a `recurring` reference inside `(SELECT max(...))` is a correlated subquery and is not allowed), compute `max_id` as a column of `acc` instead: `acc(k, out, max_id)` with `max_id` carried forward as `a.max_id + 1 + len(inner rows)`.

Extend the printer: a step's clause list appends, for each child group node, `'HAS ( ' || <inner chain text, space-separated> || ' )'` or `'NOT ( … )'`, where the inner chain text is the same per-step rendering (combinator keyword, clauses, alias) joined by spaces. Since the printer is not recursive in SQL, render groups with a `USING KEY` fold over node depth: leaves first, then steps whose groups are rendered, then the root; write it as `tree_selector_to_treeql` using the same fold shape the compiler in Task 5 uses.

`tree_steps_group(sel, step_alias, kind, inner)`: find the step node whose `alias = step_alias`, append a group node under it and `inner`'s rows renumbered from `max(node_id) + 2` with the inner selector's steps re-parented under the group (drop `inner`'s own `selector` node; first inner step's `op` becomes `desc` when NULL).

```python
# test/css_parser.py
"""A small recursive-descent parser for duckent's v0 css selector grammar, producing TREE_SELECTOR rows.
Stands in for the extension's built-in parser; must agree with tree_css_lower (sql/09_css.sql) on every corpus row.
Grammar (v0): complex := compound (combinator compound)*
              combinator := ws | '>' | '+' | '~'      (desc, child, next, after)
              compound := [type] simple* ['@' name]
              type := ident | '"' ident '"'
              simple := '.' ident | '#' ident | '[' ident op value ']' | ':' ident [ '(' arg ')' ]
              op := '=' | '^=' | '$=' | '*='  ;  value := '"' text '"' | ident | number
              :not(complex) and :has([combinator] complex) nest; :first-child is a built-in pseudo.
"""
import os, re

class CssError(Exception):
    pass

TOKEN = re.compile(r"""\s+|>|\+|~|\.|#|\[|\]|\(|\)|:|@|\^=|\$=|\*=|=|"[^"]*"|'[^']*'|-?\d+(?:\.\d+)?|[A-Za-z_][A-Za-z0-9_-]*|.""", re.S)

def tokenize(text):
    out = []
    for m in TOKEN.finditer(text):
        t = m.group(0)
        out.append(("ws", None) if t.isspace() else (t, m.start()))
    return out

class Parser:
    def __init__(self, text):
        self.text = text
        self.toks = tokenize(text)
        self.i = 0
        self.rows = []
        self.mn08 = os.environ.get("DUCKENT_MUTANT") == "MN08"

    def peek(self, k=0):
        j = self.i + k
        return self.toks[j][0] if j < len(self.toks) else None

    def take(self):
        t = self.toks[self.i]; self.i += 1; return t

    def error(self, msg):
        pos = self.toks[self.i][1] if self.i < len(self.toks) else len(self.text)
        raise CssError(f"css: {msg} at position {pos} in {self.text!r}")

    def node(self, parent_id, kind, value=None, op=None, arg=None, alias=None):
        row = {"node_id": len(self.rows), "parent_id": parent_id, "kind": kind, "value": value, "op": op, "arg": arg, "alias": alias}
        self.rows.append(row); return row

    def skip_ws(self):
        saw = False
        while self.peek() == "ws": self.i += 1; saw = True
        return saw

    def ident(self):
        t = self.peek()
        if t is None or not re.match(r"^[A-Za-z_][A-Za-z0-9_-]*$", t): self.error("expected a name, got " + repr(t))
        return self.take()[0]

    def parse(self):
        root = self.node(None, "selector")
        self.skip_ws()
        self.complex(root["node_id"], first_op=None, in_group=False)
        self.skip_ws()
        if self.i < len(self.toks): self.error("unexpected " + repr(self.peek()))
        return self.rows

    def complex(self, parent_id, first_op, in_group):
        op = first_op
        # a relative selector inside :has may start with a combinator
        if in_group and self.peek() in (">", "+", "~"):
            op = {">": "child", "+": "next", "~": "after"}[self.take()[0]]; self.skip_ws()
        while True:
            step = self.node(parent_id, "step", op=op)
            self.compound(step, in_group)
            saw_ws = self.skip_ws()
            t = self.peek()
            if t in (">", "+", "~"):
                self.take(); self.skip_ws()
                if self.peek() in (">", "+", "~"): self.error("unexpected " + repr(self.peek()))
                op = {">": "child", "+": "next", "~": "after"}[t]
                if self.mn08 and op == "child": op = "desc"   # MN8: mis-group a > b c
            elif saw_ws and t not in (None, ")"):
                op = "desc"
            else:
                return

    def compound(self, step, in_group):
        sid = step["node_id"]; seen = False
        t = self.peek()
        if t and (re.match(r"^[A-Za-z_]", t) or t.startswith('"')):
            self.node(sid, "type", value=self.take()[0].strip('"')); seen = True
        while True:
            t = self.peek()
            if t == ".":
                self.take(); self.node(sid, "class", value=self.ident()); seen = True
            elif t == "#":
                self.take(); self.node(sid, "id", value=self.ident()); seen = True
            elif t == "[":
                self.take(); self.skip_ws()
                name = self.ident()
                if name.upper() == "WHERE": self.error("css has no host escape: mint a PSEUDO, or MATCH USING TREEQL")
                self.skip_ws(); opt = self.peek()
                if opt not in ("=", "^=", "$=", "*="): self.error("expected an attribute operator")
                self.take(); self.skip_ws()
                v = self.peek()
                if v is None or v == "]": self.error("expected an attribute value")
                v = self.take()[0]
                lit = v if (v.startswith('"') or v.startswith("'") or re.match(r"^-?\d", v)) else "'" + v + "'"
                lit = "'" + lit.strip('"').strip("'") + "'" if not re.match(r"^-?\d", v) else lit
                inner = lit.strip("'")
                if opt == "=": op, arg = "=", lit
                elif opt == "^=": op, arg = "LIKE", f"'{inner}%'"
                elif opt == "$=": op, arg = "LIKE", f"'%{inner}'"
                else: op, arg = "LIKE", f"'%{inner}%'"
                self.skip_ws()
                if self.peek() != "]": self.error("unclosed [ attribute selector")
                self.take(); self.node(sid, "attr", value=name, op=op, arg=arg); seen = True
            elif t == ":":
                self.take(); name = self.ident()
                if name in ("has", "not"):
                    if self.peek() != "(": self.error("expected ( after :" + name)
                    self.take(); self.skip_ws()
                    g = self.node(sid, name)
                    self.complex(g["node_id"], first_op="desc", in_group=True)
                    self.skip_ws()
                    if self.peek() != ")": self.error("unclosed :" + name + "(")
                    self.take()
                elif self.peek() == "(":
                    self.take(); depth = 1; arg = []
                    while depth and self.peek() is not None:
                        tok = self.take()[0]
                        if tok == "(": depth += 1
                        elif tok == ")": depth -= 1
                        if depth: arg.append(tok if tok != "ws" else " ")
                    if depth: self.error("unclosed :" + name + "(")
                    self.node(sid, "pseudo", value=name, arg="".join(arg).strip())
                else:
                    self.node(sid, "pseudo", value=name)
                seen = True
            elif t == "@":
                self.take(); step["alias"] = self.ident()
                if in_group: self.error("capture inside :has/:not has no row to bind")
            else:
                break
        if not seen: self.error("expected a selector, got " + repr(self.peek()))

def parse(text):
    return Parser(text).parse()

def sql_lit(v):
    return "NULL" if v is None else "'" + str(v).replace("'", "''") + "'"

def to_sql(rows):
    parts = []
    for r in rows:
        parts.append("{node_id: %d, parent_id: %s, kind: %s, value: %s, op: %s, arg: %s, alias: %s}" % (

```

- [ ] **Step 3: Write the lowering**

The lowering is a bottom-up fold over the css parse rows. Each css node produces a JSON value describing a step chain: `{"steps": [{"op": ..., "clauses": [...], "groups": [...], "alias": ...}, ...]}`. Postfix wrappers (`class_selector`, `id_selector`, `attribute_selector`, `pseudo_class_selector`) take their inner selector's chain and add a clause or a group to its last step; combinator nodes concatenate the left chain and the right chain with the right chain's first step given the combinator's `op`; `tag_name`/`identifier` start a chain with a `type` clause; `arguments` lower to their single child's chain; `ERROR`/`stylesheet` pass through their single child, except that an `ERROR` containing a `MISSING` token or trailing unlowerable children refuses.

```sql
-- sql/09_css.sql
-- Lower tree-sitter-css parse rows (sitting_duck's parse_ast_list_table(sel, 'css')) to a TREE_SELECTOR.
-- Bottom-up fold over the css tree; each node yields a JSON step-chain. tree_css_json_to_ir numbers the rows.
CREATE OR REPLACE MACRO tree_css_lower(rows) AS (
  WITH RECURSIVE n AS (SELECT (r).node_id AS node_id, (r).parent_id AS parent_id, (r).type AS type, (r).name AS name FROM (SELECT unnest(rows) AS r)),
  kids AS (SELECT parent_id AS node_id, count(*) AS n FROM n WHERE type NOT IN ('.', '#', ':', '[', ']', '(', ')', '=', '^=', '$=', '*=', '>', '+', '~', '"', 'string_content') GROUP BY parent_id),
  f USING KEY (node_id) AS (
    -- leaves: names become type clauses; punctuation lowers to nothing (filtered by kids)
    SELECT node_id, CASE type
        WHEN 'tag_name'   THEN json_object('steps', json_array(json_object('op', NULL, 'clauses', json_array(json_object('kind', 'type', 'value', name)), 'groups', json_array(), 'alias', NULL)))
        WHEN 'identifier' THEN json_object('steps', json_array(json_object('op', NULL, 'clauses', json_array(json_object('kind', 'type', 'value', name)), 'groups', json_array(), 'alias', NULL)))
        WHEN 'class_name' THEN json_object('leaf', json_object('kind', 'class', 'value', name))
        WHEN 'id_name'    THEN json_object('leaf', json_object('kind', 'id', 'value', name))
        WHEN 'attribute_name' THEN json_object('attr_name', name)
        WHEN 'string_value'   THEN json_object('lit', trim(name, '"'''))
        WHEN 'plain_value'    THEN json_object('lit', name)
        WHEN 'integer_value'  THEN json_object('lit', name)
        ELSE NULL END::VARCHAR AS j
    FROM n WHERE node_id NOT IN (SELECT node_id FROM kids)
    UNION ALL
    SELECT p.node_id, tree_css_combine(p.type, p.name, list(struct_pack(type := c.type, name := c.name, j := d.j) ORDER BY c.node_id)) AS j
    FROM (SELECT x.* FROM n x JOIN kids k ON k.node_id = x.node_id LEFT JOIN (SELECT node_id FROM recurring.f) done ON done.node_id = x.node_id WHERE done.node_id IS NULL) p
    JOIN n c ON c.parent_id = p.node_id AND c.type NOT IN ('.', '#', ':', '[', ']', '(', ')', '=', '^=', '$=', '*=', '>', '+', '~', '"', 'string_content')
    JOIN (SELECT * FROM recurring.f) d ON d.node_id = c.node_id
    GROUP BY p.node_id, p.type, p.name
    HAVING count(*) = (SELECT k.n FROM kids k WHERE k.node_id = p.node_id))
  SELECT tree_css_json_to_ir((SELECT j FROM f WHERE node_id = (SELECT min(node_id) FROM n WHERE parent_id IS NULL))) FROM (SELECT 1));
```

`tree_css_combine(type, name, children)` is a pure macro over the children's JSON that implements the rules above (the css node's `name` is its source text, used for `pseudo_class_selector` to read the pseudo name and for `attribute_selector` to read the operator token when the token rows were filtered), refusing with `error('css: ...')` for `[WHERE`, `MISSING`, and unlowerable shapes; `tree_css_json_to_ir(j)` walks the JSON chain (steps, clauses, groups, nested chains) and emits numbered `TREE_SELECTOR` rows with the same numbering discipline as `tree_steps` (outer chain first, then each group node followed by its inner rows). `tree_parse_css(text)` is `tree_css_lower((SELECT list({node_id, parent_id, type, name} ORDER BY node_id) FROM parse_ast_list_table(text, 'css')))`. The two JSON helpers may use recursive CTEs freely (they are never fed to `query()`); keep the `recurring` references in FROM position.
